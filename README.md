# ЧистоДома

Статический сайт услуг уборки квартир в Санкт-Петербурге.

Сайт: https://zhigunovme.github.io/chistodoma/

## Структура

- `index.html` — страница сайта.
- `assets/` — CSS, JavaScript и изображения.
- `fonts/` — локальные шрифты и лицензии.
- `.nojekyll` — публикация статических файлов без обработки Jekyll.

## Локальный запуск

Из папки проекта запустите `python3 -m http.server 8000` и откройте http://localhost:8000/.

Для проверки пути GitHub Pages запустите сервер из родительской папки и откройте http://localhost:8000/chistodoma/.

## Публикация

GitHub Pages публикует корень ветки `main`. Изменения в этой ветке обновляют сайт.
В репозитории хранится готовая статическая версия; исходники сборки не включены.

## Ограничения

Форма заявки проверяет заполнение полей и показывает сообщение об успехе, но не отправляет данные. Для приёма заявок требуется отдельная интеграция.
