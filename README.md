# ЧистоДома — лендинг клинингового сервиса

Адаптивный сайт услуг уборки квартир в Санкт-Петербурге. Посетитель может сравнить виды уборки, увидеть результат «до и после» и рассчитать предварительную стоимость с учётом площади и дополнительных услуг.

**[Открыть сайт →](https://zhigunovme.github.io/chistodoma/)**

## Возможности

- **Калькулятор стоимости:** три вида уборки, площадь от 15 до 200 м², минимальная сумма заказа и дополнительные услуги с выбором количества.
- **Мгновенный пересчёт:** итог обновляется при изменении параметров без перезагрузки страницы.
- **Сравнение «до и после»:** интерактивные изображения для каждого вида уборки с управлением мышью, касанием и клавиатурой.
- **Карусель отзывов:** переключение карточек и автоматическая прокрутка с паузой при наведении или фокусе.
- **Форма заявки:** модальное окно, маска российского номера телефона и сообщения об ошибках заполнения.
- **Структура лендинга:** преимущества, этапы заказа, услуги, отзывы, FAQ и контакты.

## Технические решения

HTML5, CSS3 и JavaScript без сторонних JavaScript-библиотек. Сайт размещается как набор статических файлов и не требует CMS или базы данных.

Фотографии услуг и главного экрана используются в формате WebP. Для изображения первого экрана и двух шрифтов задана предварительная загрузка, для фотографий ниже — отложенная. Шрифты подключены локально, CSS и JavaScript минифицированы.

В интерфейсе предусмотрены семантические разделы, ссылка перехода к основному содержимому, подписи элементов управления и озвучиваемое обновление стоимости через `aria-live`. Блоки сравнения поддерживают стрелки, Home и End. Анимация учитывает настройку `prefers-reduced-motion`.

За расчёт отвечает отдельная функция: она учитывает тариф, минимальную стоимость и выбранные дополнения. Поле площади, ползунок и кнопки изменения значения синхронизированы; элементы управления блокируются на допустимых границах.

## Что показывает проект

Сочетание визуальной подачи услуги и прикладной логики: адаптивную вёрстку, расчёт стоимости, синхронизацию элементов формы и интерактивную демонстрацию результата. Отдельное внимание уделено управлению с клавиатуры и подготовке ресурсов к загрузке.

## Демо

Калькулятор выполняет предварительный расчёт в браузере. Форма заявки демонстрирует проверку полей и состояние успешного заполнения; для отправки данных требуется подключение сервера или сервиса форм.

## Локальный запуск

```bash
python3 -m http.server 8000
```

Откройте [localhost:8000](http://localhost:8000/). В репозитории находится готовая статическая версия; сборка для запуска не требуется.
